# NoorAI
Full-stack Islamic web app includes AI chatbot, prayer tracker, Dua finder. Built with FastAPI, React, and RAG.

## Design
Full UI design system and screen mockups built in Figma.
9 screens designed including login, dashboard, prayer tracker,
AI chatbot, dua finder, prayer times, zakat calculator,
and profile settings.

Design reference: `/design/noorai-screens.html`
